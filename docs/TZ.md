# ТЗ проекта "Огородом"

Актуальное рабочее ТЗ для Telegram-бота "Огородом".

## Базовый MVP

- Telegram-бот для задач огорода, участков, зон, посадок, журнала работ, напоминаний, quiet hours, backup и диагностики.
- Архитектура: `bot -> services -> repositories -> db`.
- Бизнес-логика живет в `services`, SQL в `repositories`, Telegram UI в `bot` и `ui`.
- Секреты, `.env`, базы, backup, логи и кэш не коммитятся.
- Бот работает без внешних runtime-зависимостей, через стандартную библиотеку Python и прямой Telegram Bot API.

## Интерактивный интерфейс

- `/start` показывает главное кнопочное меню.
- Разделы: `Задачи`, `Огород`, `Журнал`, `Настройки`, `Помощь`.
- Поддерживаются reply-клавиатуры, inline-кнопки, `callback_query`, `answerCallbackQuery`, `reply_markup`, `editMessageText`.
- Старые команды остаются рабочими.
- Диалоговые состояния хранятся в SQLite и переживают рестарт процесса.

## Критичные доработки

- `docs/TZ.md` должен быть в GitHub-репозитории.
- Реализовать `/today` и экран "Сегодня": просроченные задачи, задачи на сегодня, ближайшие на 3 дня, inline-действия `Готово`, `Отложить`, `Пропустить`, `Подробнее`.
- Добавить статусы задач: `open/active`, `done`, `snoozed`, `skipped`, `canceled`, `archived`.
- Реализовать `Отложить`: 1 час, вечер, завтра, выбранная дата/время.
- Реализовать `Пропустить`: с причиной или без; для повторяющейся задачи создавать следующее повторение.
- Добавить `/pause` и `/resume` для выключения/включения уведомлений.
- Добавить `/water`, `/mow`, `/treat` как MVP-алиасы к журналу работ.
- Добавить справочник `work_types`: `watering`, `mowing`, `treatment` и базовые типы работ.
- Добавить `/log`: без аргументов пошаговый диалог, с аргументом быстрое создание записи журнала.
- Добавить `wait_until_date` для задач/журнала; для `/treat` поддержать срок ожидания датой или количеством дней.
- Добавить `/delete_me` с подтверждением; удаляются все данные текущего пользователя каскадом.
- Добавить startup backup перед основной работой bot/worker с защитой от слишком частого backup.
- Добавить dry-run worker: `python -m ogorodom_bot.worker --dry-run` или `python -m ogorodom_bot.manage dry-run-reminders`.
